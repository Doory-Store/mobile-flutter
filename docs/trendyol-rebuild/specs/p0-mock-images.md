# P0 · صور الـ Mock وقاعدة 2:3

يغطي [#12](https://github.com/Doory-Store/mobile-flutter/issues/12). المكوّن البصري هو `DooryImage`. البيانات تمر من repository، والـ Widget لا يستورد ملف fixture.

## القاعدة

صورة المنتج نسبة عرضها إلى ارتفاعها 2:3. البئر في الواجهة بالنسبة نفسها، و`BoxFit.cover` من المركز. الأصل المرسوم بالنسبة نفسها يظهر كاملاً بلا قص. صورة بنسبة مختلفة تُقص من المركز، والبئر لا يتمدد ولا يترك أشرطة.

| البئر | العرض × الارتفاع | أين |
|---|---|---|
| بطاقة عمود على 411 dp | 193.5 × 290.25 | `ProductCardVertical` |
| بطاقة رف | 137 × 205.5 | `ProductCardRail` |
| معرض صفحة المنتج | 411 × 616.5 | P6، والأصل نفسه يكفي |
| مصغّر لون | 58 × 87 | P6 |
| صورة سلة | 56 × 84 | P7 |
| صورة طلب | 36 × 54 | P10. القياس 36×48 أقرب إلى 3:4، وصور دوري تبقى 2:3 داخل الإطار مع `cover` |

`cover` قرار محسوم في [`p0-foundation.md`](p0-foundation.md) بدل `contain` القديم، لأن لقطات القائمة ممتلئة ولأن الأصل يُنتج بالنسبة نفسها.

## DooryImage

### التشريح

| الجزء | القيمة |
|---|---|
| النسبة | خاصية، افتراضها `2 / 3` |
| الملاءمة | `BoxFit.cover`، المحاذاة center |
| الخلفية قبل التحميل وبعد الخطأ | `surfaceSubtle` |
| الظهور | `fade` 200ms، ويصبح 0 مع `disableAnimations` |
| نصف القطر | 0 للمنتج. المربعات اللاحقة (فئة) تستخدم `radius8` أو `radius12` عبر الخاصية |

أيقونة البديل `image_outlined` بحجم 32 ولون `textMuted`، في وسط البئر. تُستخدم عندما المصدر null أو فشل التحميل.

### مصدر الصورة

| بداية السلسلة | العرض |
|---|---|
| `assets/` | `Image.asset` |
| `http://` أو `https://` | `CachedNetworkImage` |
| null أو فارغ | بئر البديل |

ذاكرة الصور الشبكية تُحد بـ `عرض البئر × devicePixelRatio` حتى لا تُحمَّل صورة 1200px داخل بطاقة 137 dp.

### الحالات

| الحالة | الرسم |
|---|---|
| loading | `SkeletonBox` يملأ البئر بالنسبة نفسها |
| loaded | الصورة بعد `fade` |
| empty | بئر وأيقونة |
| error | البئر والأيقونة نفسها، بلا رسالة خطأ داخل البطاقة |
| reduced motion | ظهور بلا مدة |

### RTL والوصول

الصورة لا تُقلب. التسمية الدلالية هي اسم المنتج الذي يمرّره الأب، وتُخفى عندما تكون البطاقة قد أعلنت الاسم حتى لا يتكرر. في معرض لاحقاً التسمية «صورة {الاسم}».

### الخصائص

| الخاصية | النوع | الافتراضي | الدور |
|---|---|---|---|
| `source` | String أو null | null | أصل أو رابط |
| `aspectRatio` | double | `2 / 3` | عرض ÷ ارتفاع |
| `fit` | BoxFit | `cover` | الملاءمة |
| `radius` | double | 0 | قص الزوايا |
| `semanticLabel` | String أو null | null | وصف الصورة |

## أصول المنتجات

كل منتج fixture له ملف واحد بالنسبة 2:3، ومنه تُشتق كل الآبار.

| البند | القيمة |
|---|---|
| المسار | `assets/mock/products/<id>.jpg` |
| البكسل | 1200 × 1800 |
| الترميز | JPEG، جودة 80 |
| المعرّف | رقم المنتج في الـ fixture، مثل `1001.jpg` |
| التسجيل | المسار في `pubspec.yaml` تحت `assets/mock/` |

1200×1800 تغطي معرض 411 dp على كثافة 2.625 (حوالي 1080×1620 لازمة للعرض الكامل) بهامش بسيط، وتُصغَّر للبطاقة.

الصور مشاهد منتجات محايدة بلا شعار ترينديول، وبلا شارة خصم مرسومة داخل الصورة، وبلا نص ترويجي. إن حمل الأصل علامة تجارية لطرف ثالث تُستبدل بمشهد محلي أو بلون `surfaceSubtle` وأيقونة البديل.

## أصول ليست 2:3

[#12](https://github.com/Doory-Store/mobile-flutter/issues/12) يطلب fixtures للقنوات والفئات والمتاجر أيضاً. نسبها مختلفة حتى لا تُمدَّد صورة المنتج داخل دائرة متجر.

| النوع | المسار | البكسل | النسبة | القص لاحقاً |
|---|---|---|---|---|
| فئة | `assets/mock/categories/<slug>.jpg` | 512 × 512 | 1:1 | مربع بنصف قطر 8 أو 12 |
| متجر | `assets/mock/stores/<slug>.jpg` | 512 × 512 | 1:1 | دائرة 66 dp |
| قناة | `assets/mock/channels/<slug>.jpg` | 256 × 256 | 1:1 | بلاطة 76×66، والصورة مربع في أعلاها |
| بانر | `assets/mock/banners/<slug>.jpg` | 1233 × 315 | 411:105 | عرض كامل بارتفاع 105 dp، `cover` |

## التسمية والصدق

- اسم الملف معرّف ثابت: رقم للمنتج، وslug للفئة والمتجر والقناة والبانر. لا مسافات ولا أحرف عربية في اسم الملف.
- نموذج الـ mock يضع السلسلة في حقل الصورة، مثل `assets/mock/products/1001.jpg`.
- `sample: true` على كيانات الـ fixture، و`DemoLabel` في البطاقة أو رأس الشاشة. الصورة بلا ختم كتابي.
- تقييم أو سعر مقارن داخل fixture مسموح لأن البطاقة معلّمة. كيان بلا `sample` لا يحمل خصماً مخترعاً.
- فشل أصل مفقود يسقط إلى بئر `DooryImage` ويُبقي الاسم والسعر.

## ما يوفّره المستودع لا الصورة

المفاتيح التي يطلبها [#12](https://github.com/Doory-Store/mobile-flutter/issues/12) على طبقة البيانات، مذكورة هنا حتى يطابق شكل الصورة شكل الحالة:

| المفتاح | الأثر البصري |
|---|---|
| `ok` | الصور والنصوص |
| `empty` | `EmptyState` بلا صور منتجات |
| `error` | `ErrorState` بلا صور |
| `loading` | هياكل `SkeletonProductCard` |

الويدجت يقرأ ناتج الـ repository. تبديل المفتاح يتم خارج الشجرة، من provider التجريبي.
