## PriceBlock

### التشريح

| الجزء | الدور | يظهر عندما |
|---|---|---|
| السعر الحالي | `price` أو `priceLarge` أو `priceCompact` | `priceSyp != null` |
| السعر المرجعي | `strike` | `compareAtSyp != null` و`compareAtSyp > priceSyp` |
| خصم نصي | `captionStrong` بلون `discount`، النص «خصم {n}٪» | الشرط السابق نفسه، و`n` نسبة صحيحة مقربة |
| تقدير | `caption` بلون `textSecondary`، النص «سعر تقريبي» | `estimate == true` |

الترتيب الافتراضي صف واحد: الحالي، ثم 4 dp، ثم المشطوب، ثم 4 dp، ثم نسبة الخصم. عند ضيق العرض ينزل المشطوب ونسبة الخصم سطراً ثانياً. التقدير سطر تحت السعر دائماً. التفاصيل في [`p0-decisions.md`](p0-decisions.md) §3 و§11.

`priceSyp == null` يخفي المكوّن بالكامل. لا يُرسم `0`.

### الحالات

| الحالة | الرسم |
|---|---|
| default | سعر فقط |
| compare | سعر + مشطوب + نسبة، عندما تكون الأرقام صحيحة |
| estimate | سطر «سعر تقريبي» تحت السعر |
| hidden | لا ارتفاع عند غياب السعر |
| sample | السعر يُرسم، و`DemoLabel` يضعه الأب لا هذا المكوّن |

### RTL والوصول

محاذاة البداية. السلسلة من `formatSyp` معزولة LTR. `Semantics` يقرأ السعر الحالي، ثم «بدلاً من {المرجعي}» عند وجوده، ثم «سعر تقريبي» عند الحاجة. النسبة تُقرأ «خصم {n} بالمئة».

### الخصائص

| الخاصية | النوع | الافتراضي | الدور |
|---|---|---|---|
| `priceSyp` | int أو null | — | السعر |
| `compareAtSyp` | int أو null | null | المرجعي |
| `estimate` | bool | false | سعر تقريبي |
| `size` | `card` \| `compact` \| `large` | `card` | يختار `price` أو `priceCompact` أو `priceLarge` |

## RatingRow

يُرسم عندما `rating != null` فقط. صف بلا تقييم لا يترك فراغاً.

### التشريح

| الجزء | المقاس | الرمز |
|---|---|---|
| خمس نجوم | 12 dp، فراغ 2 dp بين كل اثنتين | الممتلئ `rating`، الفارغ `border` |
| الرقم | `captionStrong`، منزلة عشرية واحدة | `textPrimary` |
| العدد | `caption` داخل قوسين «(2009)» | `textSecondary` |
| ارتفاع الصف | 16 dp | — |
| فراغ قبل الرقم | 4 dp | — |

النجمة الجزئية تُملأ بنسبة الكسر (4.4 تعني أربعاً ممتلئة وخامسة ممتلئة 40٪). التقريب إلى نجمة كاملة غير مستخدم.

العدد يُخفى عندما يكون null أو 0.

### الحالات

| الحالة | الرسم |
|---|---|
| default | نجوم + رقم + عدد |
| no count | نجوم + رقم |
| hidden | `rating == null` |

### RTL والوصول

النجوم من البداية نحو النهاية. أيقونة النجمة لا تُقلب. القراءة: «التقييم 4.0 من 5، 2009 مراجعة» عند وجود العدد.

### الخصائص

| الخاصية | النوع | الافتراضي | الدور |
|---|---|---|---|
| `rating` | double أو null | — | من 0 إلى 5 |
| `count` | int أو null | null | عدد المراجعات |

## FavoriteButton

### التشريح

| الجزء | المقاس |
|---|---|
| منطقة اللمس | 48×44 dp |
| الدائرة المرئية | 32 dp، تعبئة `surface`، ظل `favorite` |
| الأيقونة | 20 dp |
| الموضع فوق الصورة | أعلى النهاية، حشو 4 dp عن الحافة |

### الحالات

| الحالة | الأيقونة | اللون |
|---|---|---|
| default | `favorite_border` | `textPrimary` |
| pressed | نفسها | شفافية 0.72 |
| selected | `favorite` | `danger` (افتراض [`p0-decisions.md`](p0-decisions.md) §10) |
| disabled | `favorite_border` | `textMuted`، والضغط متوقف |

الضيف لا يُعطل الزر داخل المكوّن. الأب يفتح بوابة الدخول عند الحاجة. الزر يستدعي `onPressed` في الحالتين.

### RTL والوصول

الموضع `PositionedDirectional` على النهاية، فيظهر يسار الصورة في RTL. القلب لا يُقلب.

- غير محدد: «إضافة إلى المفضلة».
- محدد: «إزالة من المفضلة»، مع حالة selected.
- الضغط لا يفتح صفحة المنتج. الحدث يتوقف عند الزر.

### الخصائص

| الخاصية | النوع | الافتراضي | الدور |
|---|---|---|---|
| `selected` | bool | false | حالة القلب |
| `onPressed` | callback | — | التبديل |
| `enabled` | bool | true | التعطيل |

## ProductCardVertical

بطاقة عمود القائمة. على 411 dp عرضها 193.5 dp. الصيغة `(viewportWidth - 24) / 2`.

### التشريح من الأعلى إلى الأسفل

| الجزء | المقاس | ملاحظة |
|---|---|---|
| الصورة | العرض × 1.5، أي 193.5×290.25 على المرجع | `DooryImage`، `cover`، نصف قطر 0 |
| القلب | كما في `FavoriteButton` | فوق الصورة |
| عدد الألوان | كما في `ColorCountBadge` | فوق الصورة |
| شارة النفاد | `DooryBadge` هيئة `danger` على أسفل البداية، حشو 8 | عندما `available == false`، والصورة بشفافية 0.5 |
| كتلة النص | حشو 8 من كل جهة | محاذاة البداية |
| العنوان | سطران كحد أقصى | `cardBrand` للاسم التجاري ثم مسافة ثم `cardTitle` للاسم. اسم تجاري فارغ يعني الاسم كله بوزن 400 |
| فراغ | 4 | — |
| `RatingRow` | 16 أو 0 | — |
| فراغ | 4 | عند وجود التقييم |
| `PriceBlock` | حجم `card` | — |
| «نفدت الكمية» أو «غير متاح للشراء حاليًا» | `captionStrong` بلون `danger` | الأولى عند `available == false`، والثانية عند `available && !canPurchase` |
| `DemoLabel` | تحت آخر سطر، فراغ 6 | عندما `sample == true` |

ارتفاع البطاقة يتبع المحتوى. القياس ≈ 408 dp لبطاقة بسطرين وتقييم وسعرين، وهو مرجع لا قيد. الشبكة صفوف بارتفاع أطول بطاقة في الصف، حتى يكبر النص عند 1.3× من غير قص.

لا حد، ولا ظل، ولا نصف قطر على جسم البطاقة. الفراغ بين الأعمدة وبين الصفوف 8 dp، وهامش الصفحة الأفقي 8 dp.

### الحالات

| الحالة | الرسم |
|---|---|
| default | صورة وعنوان وسعر |
| pressed | طبقة `primarySubtle` على البطاقة لمدة `press`. القلب مستقّل |
| favorite selected | القلب ممتلئ |
| no rating | كتلة التقييم محذوفة |
| no price | `PriceBlock` محذوف |
| sold out | شفافية الصورة، والشارة، وسطر «نفدت الكمية» |
| unavailable | سطر «غير متاح للشراء حاليًا» |
| image empty | بئر `DooryImage` البديل، وباقي النص يبقى |
| sample | `DemoLabel` ظاهر |
| loading | ليس حالة البطاقة. الأب يعرض `SkeletonProductCard` |

ضغط جسم البطاقة يفتح `/p/:ref`. ضغط القلب لا يفتح الصفحة.

### RTL والوصول

النص والصورة من البداية. القلب على النهاية.

البطاقة زر واحد تسميته ناتج `productSemantics`: الاسم التجاري، الاسم، السعر، التقدير، النفاد، التقييم. القلب عقدة منفصلة بعده في ترتيب التركيز. الصورة بلا وصف مكرر حتى لا يُقرأ الاسم مرتين.

### الخصائص

| الخاصية | النوع | الافتراضي | الدور |
|---|---|---|---|
| `ref` | String | — | مسار المنتج |
| `name` | String | — | اسم المنتج |
| `brand` | String أو null | null | الماركة أو المتجر في أول العنوان |
| `image` | String أو null | null | أصل أو رابط |
| `priceSyp` | int أو null | null | السعر |
| `compareAtSyp` | int أو null | null | المرجعي |
| `estimate` | bool | false | سعر تقريبي |
| `rating` | double أو null | null | التقييم |
| `ratingCount` | int أو null | null | العدد |
| `colorCount` | int أو null | null | شارة الألوان |
| `available` | bool | true | المخزون |
| `canPurchase` | bool | true | قابلية الشراء |
| `favorite` | bool | false | حالة القلب |
| `sample` | bool | false | بيانات تجريبية |
| `onTap` | callback | — | فتح المنتج |
| `onFavorite` | callback | — | القلب |

## ProductCardRail

بطاقة الرف الأفقي. البنية نفسها مع هذه الفروق:

| الجزء | القيمة |
|---|---|
| العرض | 137 dp ثابت |
| الصورة | 137 × 205.5 dp |
| حشو النص | 6 dp |
| ارتفاع تقريبي لبطاقة كاملة | ≈ 300 dp، والمحتوى هو الذي يحدّد |
| الفراغ بين البطاقات | 8 dp |
| حشو الرف | 8 dp على البداية والنهاية |

`PriceBlock` بالحجم `card`. العنوان سطران. القلب وشارة الألوان بالمواضع نفسها.

الرف `ListView` أفقي يبدأ من البداية الخطية. لا سهم تراكب في P0.

### الخصائص

خصائص `ProductCardVertical` نفسها. العرض ثابت داخل المكوّن ولا يأتي من الأب، حتى تبقى البطاقة 137 على أي هاتف. على شاشة أعرض من 600 dp يبقى العرض 137، وتظهر بطاقات أكثر.

## الشبكة والرف

| القاعدة | القيمة |
|---|---|
| أعمدة القائمة | 2 |
| الهامش والفراغ | 8 dp |
| بداية الرف | البداية الخطية |
| السحب | أفقي مع اتجاه القراءة |

## ما يُترك

شريط Plus الوردي، وكوبون «خصم 75٪» كملصق حملة، والعدّاد التنازلي، ودائرة الخصم الكبيرة على الصورة، وشارة «شحن مجاني» ما لم يأتِ حقل توصيل حقيقي في مرحلة لاحقة. الخصم الوحيد على البطاقة هو نسبة `PriceBlock` المحسوبة من سعرين صادقين.
