# P0 · الرموز

المصدر الذي يحدّثه [#6](https://github.com/Doory-Store/mobile-flutter/issues/6): `DooryColors` ثم `DooryTokens` ثم `dooryTheme()`. الشاشات تقرأ الاسم من `Theme.of(context)` أو `DooryTokens.of(context)`.

القيم الجديدة معلّمة بـ «جديد». الباقي قائم في `lib/core/theme/` ويبقى اسمه.

## 1. الألوان

| الرمز | Hex | الدور في P0 |
|---|---|---|
| `primary` | `#F27A1A` | تعبئة الزر الأساسي، التبويب النشط، أيقونة الحالة، الشعار. لون علامة، لا لون نص صغير على الأبيض |
| `primaryHover` | `#D56B17` | ضغط الزر الأساسي |
| `primarySubtle` | `#FFF3E8` | دائرة الفراغ، ضغط الأسطح الفاتحة، صف غير المقروء لاحقاً. يقابل القياس `#FFFBF8` في عمود الفئات، والمعتمد قيمة دوري هذه |
| `surface` | `#FFFFFF` | البطاقات، الأوراق، الشريط، آبار الصور |
| `surfaceSubtle` | `#F5F5F5` | حقل البحث، الهيكل العظمي، الأسطح الخاملة |
| `surfaceCanvas` | `#FAFAFA` | جديد. خلفية صفحات المجموعات (الحساب) والقوائم الرمادية الهادئة |
| `surfaceInverse` | `#333333` | أسطح عكسية نادرة |
| `textPrimary` | `#333333` | العناوين والنص الأساسي والتبويب الخامل |
| `textSecondary` | `#666666` | الوصف، والسعر المشطوب، ونص الفراغ |
| `textMuted` | `#999999` | تلميح زخرفي فقط. لا يُستخدم لسعر أو قيمة يقرأها المتسوّق. انظر [`p0-decisions.md`](p0-decisions.md) §4 |
| `textOnStrong` | `#FFFFFF` | نص وأيقونة فوق `primary` |
| `border` | `#E6E6E6` | الفواصل وحدود الـ Chip الخامل |
| `borderControl` | `#858585` | حد الزر الثانوي عند الحاجة إلى حافة أوضح |
| `cardPrice` | `#C2410C` | سعر البطاقة وكل سعر مكتوب بحجم `price` على `surface`. التباين على الأبيض 5.18:1 |
| `discount` / `danger` | `#BB0000` | خصم حقيقي، وخطأ، وقلب مفضّل ممتلئ |
| `success` | `#137333` | نص نجاح |
| `successSurface` | `#E7F9EF` | جديد. خلفية شارة نجاح. أخضر ترينديول `#0BC15C` يُستبدل بهذا الزوج |
| `rating` | `#FFC000` | نجمة ممتلئة عند وجود تقييم |
| `shadowCard` | `#14000000` | ظل الورقة وشريط التبويب |
| `shadowFavorite` | `#33000000` | ظل دائرة القلب |

`#F27A1A` على `#FFFFFF` = 2.77:1. هذا تحت 4.5:1 للنص العادي وتحت 3:1 للنص الكبير ولمكوّنات الواجهة. لذلك:

- نص السعر على البطاقة، ورابط «رؤية الكل»، وأي نص برتقالي صغير على الأبيض: `cardPrice`.
- تعبئة الزر والتبويب والشعار: `primary`. نص الزر `textOnStrong` على هذه التعبئة استثناء هوية موثّق، والزر يُعرف بشكله المملوء. لا تُغمَّق التعبئة.
- لون `priceLarge` (18sp) قرار مفتوح. الافتراض المعتمد: `primary`، والتفصيل في [`p0-decisions.md`](p0-decisions.md) §3.

رموز تبقى في الملف ولا تدخل مكوّنات P0: `previewPlus`، `shortcut*`، `tile*`، `footerBand`، `footerBandText`. حذفها يكسر الواجهة الحالية قبل استبدالها، واستخدامها في الشاشات الجديدة يعيد Plus وألوان الاختصارات القديمة.

## 2. التباعد

يُضاف `s6` إلى `DoorySpacing`. الباقي قائم.

| الرمز | dp | الاستخدام |
|---|---|---|
| `s4` | 4 | فراغ القلب عن حافة الصورة، فراغ بين سعر وسعر مشطوب |
| `s6` | 6 | جديد. فراغ بلاطات الفئات لاحقاً، وتباعد الـ Chip الملفوف |
| `s8` | 8 | هامش الشبكة والرف، وحشو نص البطاقة، والفراغ بين البطاقات |
| `s12` | 12 | هامش `GroupCard` الأفقي، وحشو الـ Chip الأفقي |
| `s16` | 16 | هامش القوائم والأزرار والنماذج. `gutter` يبقى 16 |
| `s20` | 20 | فراغ استثنائي داخل ورقة |
| `s24` | 24 | فراغ بين رسالة الفراغ والزر |
| `s32` | 32 | فراغ قسم حقيقي |
| `s40` | 40 | فراغ شاقولي في حالات الفراغ |
| `s48` | 48 | منطقة لمس الرأس |

هامش الصفحة نوعان:

| الاسم | dp | أين |
|---|---|---|
| `gutterDense` | 8 | شبكات المنتجات والرفوف |
| `gutter` | 16 | القوائم، الأزرار بعرض الشاشة، النماذج |

على شاشة المرجع 411 dp، عرض بطاقة العمود:

`(411 - 8 - 8 - 8) / 2 = 193.5 dp`

الصيغة العامة: `(viewportWidth - gutterDense * 3) / 2`.

## 3. أنصاف الأقطار

| الرمز | dp | الاستخدام |
|---|---|---|
| `radius4` | 4 | جديد. زر `h36`، شارة نصية، حقل مضغوط |
| `radius6` | 6 | جديد. زر `h40` و`h48`، Chip المقاس لاحقاً |
| `radius8` | 8 | `radiusCard` القائم. `GroupCard`، زر `h45` و`h53`، بلاطة فئة |
| `radius12` | 12 | جديد. الحافة العلوية لـ `DoorySheet`، الحوار |
| `radiusPill` | ارتفاع العنصر ÷ 2 | البحث، والـ Chip، والدائرة. يحل محل `radiusSearch = 20` في حقل البحث الجديد. حقل بارتفاع 38 نصف قطره 19 |

الدائرة `BoxShape.circle` أو `StadiumBorder`، لا رقم ثابت 999 داخل الشاشات. الرمز `radiusPill` في `DooryTokens` قيمته 999 ليستخدمها من يحتاج نصف قطر «كامل» قبل معرفة الارتفاع.

## 4. الحدود

| الدور | السماكة | اللون |
|---|---|---|
| فاصل الصفوف | شعرة: 1px فيزيائي (`BorderSide.width` بقيمة 0 في Flutter) | `border` |
| حد Chip خامل وبطاقة مجموعة عند الحاجة | 1 dp | `border` |
| حد زر ثانوي | 1 dp | `borderControl` |
| حد زر بإطار | 1 dp | `primary` |
| حلقة التركيز | 2 dp مع إزاحة 2 dp خارج الشكل | `primary` |

بطاقات المنتج بلا حد. الصفحة البيضاء والفراغ 8 dp يفصلان البطاقات.

## 5. الظل والارتفاع

البطاقات والشريط العلوي `elevation: 0`. الظل حالة استثناء.

| الاسم | المواصفة | أين |
|---|---|---|
| بلا | `elevation: 0` | بطاقة منتج، `GroupCard`، شريط علوي |
| `favorite` | إزاحة `(0, 2)`، ضبابية 2، لون `shadowFavorite` | دائرة القلب فوق الصورة |
| `bar` | حد علوي شعرة بلون `border`، ثم ظل إزاحة `(0, -2)` وضبابية 6 ولون `shadowCard` | أعلى `BottomTabBar`. القياس تدرّج ≈ 3 dp من `#F7F7F7` |
| `sheet` | إزاحة `(0, -8)`، ضبابية 24، لون `shadowCard` | الورقة السفلية فوق طبقة التعتيم |

طبقة تعتيم الورقة: أسود بشفافية 40٪ (`#66000000`). الرقم غير مقاس في اللقطات، وهو الافتراض المعتمد في [`p0-decisions.md`](p0-decisions.md) §6.

## 6. مقاسات الأيقونات

| الرمز | dp | أين |
|---|---|---|
| `iconMeta` | 12 | نجمة التقييم |
| `iconChevron` | 16 | سهم الصف، ويتجه إلى النهاية الخطية |
| `iconInline` | 20 | أيقونة داخل صف حساب، قلب داخل دائرته |
| `iconChrome` | 24 | شريط علوي، تبويب، إغلاق الورقة. الرسم البصري للتبويب ≈ 20 داخل صندوق 24 |
| `iconEmpty` | 32 | أيقونة داخل دائرة الفراغ 64 |

أيقونات Material outlined في الخمول وfilled في النشاط حيث يوجد الزوج. الأيقونة الاتجاهية الوحيدة هي السهم. البحث والسلة والقلب والنجمة والشعار لا تُقلب.

## 7. الحركة

| الرمز | المدة | المنحنى | الاستخدام |
|---|---|---|---|
| `press` | 100ms | `easeOut` | تغيّر لون الضغط |
| `fade` | 200ms | `easeOut` | ظهور الصورة |
| `sheet` | 250ms | `easeOut` ( decelerate ) | فتح الورقة وإغلاقها |
| `shimmer` | 1200ms | خطي متكرر | وميض الهيكل. يتوقف مع `disableAnimations` ويبقى اللون `surfaceSubtle` |

لا حركة تلقائية في الرفوف. السحب من المستخدم هو ما يحرّكها.

## 8. ربط `ColorScheme`

| خانة `ColorScheme` | الرمز |
|---|---|
| `primary` / `onPrimary` | `primary` / `textOnStrong` |
| `primaryContainer` / `onPrimaryContainer` | `primarySubtle` / `primaryHover` |
| `error` / `onError` | `danger` / `textOnStrong` |
| `surface` / `onSurface` | `surface` / `textPrimary` |
| `onSurfaceVariant` | `textSecondary` |
| `outline` | `border` |
| `outlineVariant` | `borderControl` |
| `surfaceTint` | شفاف |

`scaffoldBackgroundColor` الافتراضي `surface`. صفحات المجموعات تضع `surfaceCanvas` على جسم الصفحة نفسها.

`splashColor` و`highlightColor` على الأسطح الفاتحة: `primarySubtle`. فوق التعبئة البرتقالية: أبيض بشفافية 8٪.
