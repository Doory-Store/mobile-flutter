## DooryWordmark

الشعار كلمة «دوري» بخط Cairo Bold. لا ملف SVG في المشروع، والكلمة هي الشعار.

### التشريح

| الجزء | المقاس |
|---|---|
| النص | «دوري» ثابت |
| `compact` | دور `wordmark`: 24 / 32 / 700 |
| `display` | دور `wordmarkDisplay`: 40 / 52 / 700 |
| اللون | `primary` |
| العرض | عرض النص. لا إطار ولا خلفية |

### الحالات

| الحالة | الرسم |
|---|---|
| default | النص باللون `primary` |
| pressed | تُستخدم فقط عندما يكون الشعار زر عودة إلى الرئيسية: الشفافية 0.72 لمدة `press` |
| disabled | غير مستخدم |

### RTL والوصول

الكلمة عربية ولا تُقلب ولا تُعزل. عندما تكون زراً: `Semantics` «دوري، الرئيسية» وهدف لمس لا يقل عن 48×44. عندما تكون عنواناً داخل الشريط: `header`.

### الخصائص

| الخاصية | النوع | الافتراضي | الدور |
|---|---|---|---|
| `size` | `compact` \| `display` | `compact` | حجم السلّم |
| `onTap` | callback أو null | null | العودة إلى الرئيسية عند وجوده |

## SearchPill

حقل البحث المشترك. أيقونة الكاميرا غير موجودة، والفراغ في نهاية الحقل يُغلق.

المرجع البصري: الحقل في `10-categories` و`01-home-top`.

### التشريح

| الجزء | المقاس | الرمز |
|---|---|---|
| ارتفاع الرسم | 38 dp | — |
| نصف القطر | 19 dp (`radiusPill`) | — |
| التعبئة | — | `surfaceSubtle` |
| الحد | بلا | — |
| أيقونة البحث | 24 dp داخل منطقة لمس بعرض 40 وارتفاع يمتد إلى 48 مع صف الأب | `textPrimary` |
| موضع الأيقونة | البداية الخطية (اليمين في RTL)، حشو البداية 4 | — |
| النص | `body` 14 / 20 | التلميح `textSecondary`، المكتوب `textPrimary` |
| حشو النص | 8 dp عن الأيقونة، و12 dp عن النهاية | — |
| زر المسح | 24 dp داخل 40×38، على النهاية، يظهر مع النص غير الفارغ | `textSecondary` |

صف البحث الذي يحتوي الحقل ارتفاعه 48 dp، والحقل متمركز شاقولياً فيه. `DooryAppBar` أطول (56) والحقل متمركز فيه أيضاً.

تلميح دوري المعتمد: «ابحث عن منتج أو فئة». جملة ترينديول «البحث عن ماركة، أو منتج، أو فئة» لا تُنسخ.

### الأوضاع

| الوضع | السلوك | الرسم |
|---|---|---|
| `idle` | ليس `TextField`. الضغط يستدعي `onTap` ويفتح البحث | تلميح + أيقونة |
| `active` | `TextField` قابل للكتابة. لوحة المفاتيح عربية | تلميح يختفي عند الكتابة |
| `summary` | سطر واحد للعرض، مثل «بيجاما \| 24». الضغط يفتح البحث ولا يفتح لوحة المفاتيح | النص `body` مع `ellipsis` |

### الحالات

| الحالة | الرسم |
|---|---|
| default | التعبئة `surfaceSubtle` |
| pressed | في `idle` و`summary`: التعبئة تميل إلى `border` بنسبة خفيفة، أو طبقة `primarySubtle` |
| focused | في `active`: حلقة 2 dp بلون `primary` خارج الحبة |
| disabled | التعبئة `surfaceSubtle`، النص `textMuted`، والضغط متوقف |
| with text | زر مسح على النهاية. الضغط يفرغ النص ويبقي التركيز |

### RTL والوصول

الأيقونة على البداية. زر المسح على النهاية. النص محاذى للبداية. `textAlign: start` و`textDirection` من محيط RTL.

- `idle`: زر، التسمية «بحث».
- `active`: حقل، التسمية «بحث»، والتلميح «ابحث عن منتج أو فئة».
- زر المسح: «مسح البحث».
- ارتفاع اللمس الفعلي 48 عبر صف الأب، حتى لو بقي رسم الحبة 38.

### الخصائص

| الخاصية | النوع | الافتراضي | الدور |
|---|---|---|---|
| `mode` | `idle` \| `active` \| `summary` | `idle` | وضع الحقل |
| `hint` | String | «ابحث عن منتج أو فئة» | التلميح |
| `text` | String | فارغ | النص أو ملخص النتائج |
| `onTap` | callback | — | في `idle` و`summary` |
| `onChanged` | callback | — | في `active` |
| `onSubmitted` | callback | — | في `active` |
| `onClear` | callback | — | زر المسح |
| `autofocus` | bool | false | في `active` |
| `enabled` | bool | true | التعطيل |

## DooryAppBar

شريط الشاشات الفرعية. ارتفاعه 56 dp فوق منطقة شريط الحالة. الخلفية `surface`، والارتفاع `elevation: 0`، وبلا ظل سفلي. المحتوى يتمركز شاقولياً.

نسختان.

### نسخة `search`

من اليمين إلى اليسار في RTL:

| الجزء | المقاس |
|---|---|
| رجوع | منطقة 48×48، أيقونة 24، على البداية. تشير إلى النهاية الخطية قبل الانعكاس، وبعد `matchTextDirection` تشير نحو الخارج (اليمين في RTL) |
| `SearchPill` | يتمدد في الباقي، ارتفاع 38، هامش النهاية 8 |
| إجراءات لاحقة | كل واحدة 36×36 أو 48×48، على النهاية. السلة والمفضلة والمشاركة تأتي مع صفحة المنتج في P6، والشريط يقبل `actions` من الآن |

### نسخة `title`

| الجزء | المقاس |
|---|---|
| رجوع | 48×48 على البداية. يختفي عندما `showBack` خطأ (جذر التبويب) |
| العنوان | `toolbarTitle`، في الوسط، سطر واحد، `ellipsis`. انظر [`p0-decisions.md`](p0-decisions.md) §8 |
| إجراء نصي | على النهاية، دور `link`، منطقة لا تقل عن 48 ارتفاعاً، مثل «مسح» أو «أضف عنواناً». يختفي عندما `actionLabel` فارغ |
| إجراء أيقونة | بديل عن النصي: 48×48 |

فاصل سفلي شعرة بلون `border` في نسخة `title` فقط، كما في شاشة الطلبات الفارغة. نسخة `search` بلا فاصل حتى تلتصق بمحتوى الفئات.

### الحالات

| الحالة | الرسم |
|---|---|
| default | كما فوق |
| pressed على الرجوع أو الإجراء | طبقة `primarySubtle` |
| disabled للإجراء | النص `textMuted` والضغط متوقف |
| loading | غير مستخدم على الشريط. التحميل في جسم الصفحة |

### RTL والوصول

الرجوع على البداية البصرية (اليمين). السهم ينقلب مع الاتجاه. الشعار لا يدخل هذه النسخة.

- الرجوع: «رجوع».
- الإجراء النصي: نصه هو التسمية.
- كل أيقونة في `actions` تسمية إلزامية عبر خاصية `tooltip`.

الرجوع في Android يوافق زر النظام والرجوع التنبؤي. في iOS يوافق السحب من حافة البداية. الشريط يعرض زر الرجوع بالإضافة إلى إيماءة المنصة.

### الخصائص

| الخاصية | النوع | الافتراضي | الدور |
|---|---|---|---|
| `variant` | `search` \| `title` | `title` | النسخة |
| `title` | String | فارغ | عنوان نسخة `title` |
| `showBack` | bool | true | إظهار الرجوع |
| `onBack` | callback أو null | null | null يعني `Navigator.maybePop` |
| `search` | Widget أو خصائص `SearchPill` | — | نسخة `search` |
| `actionLabel` | String أو null | null | الإجراء النصي |
| `onAction` | callback | — | ضغط الإجراء |
| `actions` | قائمة أيقونات معنونة | فارغة | نهاية الشريط |

## DooryButton

زر واحد بأربع هيئات وخمسة ارتفاعات. العرض يحدده الأب. `expanded: true` يجعل العرض لا نهائياً، والهامش الأفقي 16 يأتي من حشو الصفحة لا من الزر.

### الأحجام

| الحجم | الارتفاع | نصف القطر | دور النص | أين يظهر المقاس |
|---|---|---|---|---|
| `h36` | 36 | `radius4` | `buttonCompact` | دعوة المفضلة، متابعة الدخول |
| `h40` | 40 | `radius6` | `button` | «إضافة إلى السلة»، تأكيد عنوان |
| `h45` | 45 | `radius8` | `button` | «متابعة التسوق»، «ابدأ التسوق». قياس زر الحساب 43 dp يقع داخل ±2 |
| `h48` | 48 | `radius6` | `button` | «تحديث». زر الفلترة المقاس 49.5 dp يستخدم هذا الحجم |
| `h53` | 53 | `radius8` | `button` | «الدفع» |

حشو أفقي داخلي 16 dp. أقل عرض 64 dp. النص سطر واحد مع `ellipsis`. عند مقياس 1.3× يُسمح بسطرين داخل الارتفاع نفسه بتصغير الحشو الشاقولي، ومن غير فيضان خارج الزر.

الزر اللاصق (`sticky`) هو الحجم `h40` أو `h53` بعرض يملأ حصته في الشريط السفلي. الشريط نفسه مكوّن P6 وP7. P0 يسلّم الزر الذي يجلس داخله.

### الهيئات

| الهيئة | التعبئة | الحد | لون النص | الضغط | التعطيل |
|---|---|---|---|---|---|
| `primary` | `primary` | بلا | `textOnStrong` | التعبئة `primaryHover` | التعبئة `border`، النص `textSecondary` |
| `outline` | شفاف | 1 dp `primary` | `cardPrice` | الخلفية `primarySubtle` | الحد `border`، النص `textMuted` |
| `secondary` | `surface` | 1 dp `borderControl` | `textPrimary` | الخلفية `primarySubtle` | التعبئة `surfaceSubtle`، النص `textMuted` |
| `text` | شفاف | بلا | `cardPrice` | الخلفية `primarySubtle` | النص `textMuted` |

نص هيئتي `outline` و`text` بلون `cardPrice` حتى يبقى النص الصغير فوق AA. حد `outline` يبقى `primary` بسمك 1 dp.

هيئة `text` حدها الأدنى 44 dp ارتفاعاً حتى لو كان سطر النص أقصر، والعرض يحتضن النص مع حشو أفقي 8.

### الحالات

| الحالة | السلوك |
|---|---|
| default | الجدول أعلاه |
| pressed | لون الضغط لمدة `press`. بلا إزاحة للتخطيط |
| disabled | الألوان في عمود التعطيل، و`onPressed` لا يُستدعى |
| loading | ارتفاع الزر وعرضه ثابتان. مؤشر دائري 20 dp بسماكة 2 يحل محل النص. اللون `textOnStrong` على `primary`، و`primary` على باقي الهيئات. اللمسات تُتجاهل |
| focused | حلقة 2 dp بلون `primary` مع إزاحة 2 dp |

### RTL والوصول

النص في الوسط. أيقونة اختيارية على بداية النص بمسافة 8 dp، وتنقلب إن كانت سهماً. `Semantics` زر، وتسميته نص الزر. في `loading` التسمية «جارٍ التنفيذ» مع حالة `busy`. في `disabled` حالة معطّل.

هدف اللمس هو ارتفاع الزر عندما يكون 44 أو أكثر. الحجم `h36` يوسّع منطقة الضغط إلى 44 شاقولياً عبر حشو الأب، والرسم يبقى 36.

### الخصائص

| الخاصية | النوع | الافتراضي | الدور |
|---|---|---|---|
| `label` | String | — | النص |
| `variant` | `primary` \| `outline` \| `secondary` \| `text` | `primary` | الهيئة |
| `size` | `h36` \| `h40` \| `h45` \| `h48` \| `h53` | `h48` | الارتفاع |
| `expanded` | bool | false | عرض الأب |
| `leading` | IconData أو null | null | أيقونة قبل النص |
| `onPressed` | callback أو null | — | null تعني disabled |
| `loading` | bool | false | حالة الانتظار |

## ما يُترك

تدرّج زر «تسجيل الدخول» من البرتقالي إلى الأحمر، والزر الاجتماعي 45 dp، وأيقونة الكاميرا في نهاية البحث، وشعار Trendyol الرسومي.
