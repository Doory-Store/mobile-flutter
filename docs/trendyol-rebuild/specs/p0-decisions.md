# P0 · قرارات مفتوحة

كل بند أدناه غير محسوم في اللقطات أو تختلف فيه الوثائق. المهندس يبني **الافتراض المعتمد** ويجعل التبديل في نقطة واحدة. لا يُترك المكوّن ناقصاً بانتظار القرار.

## 1. شكل الأرقام

القياس في ترينديول أرقام لاتينية. `PRODUCT.md` يترك الشكل مفتوحاً، و`formatSyp` اليوم يطبع أرقاماً لاتينية بفاصلة آلاف.

| | |
|---|---|
| الافتراض المعتمد | أرقام لاتينية `0–9`، فاصلة `,` كل ثلاثة أرقام، والسالب قبل الرقم |
| المثال | `1,250 ل.س` و`-1,250 ل.س` |
| العزل | السلسلة كلها داخل `\u2066` … `\u2069` حتى يبقى السعر متصلاً داخل RTL |
| البديل | أرقام عربية-هندية `٠١٢٣٤٥٦٧٨٩` مع الفاصل العربي |
| مكان التبديل | `formatSyp` فقط. المكوّنات لا تنسّق رقماً بنفسها |

## 2. رسم العملة

`README.md` و`PRODUCT.md` يكتبان «ل.س». نص المهمة يكتب «ل.س.» والنقطة قد تكون نهاية الجملة.

| | |
|---|---|
| الافتراض المعتمد | `ل.س` بلا نقطة ثالثة، ومسافة واحدة قبلها: `1,250 ل.س` |
| البديل | `ل.س.` بنقطة بعد السين |
| مكان التبديل | الثابت نفسه داخل `formatSyp` |

## 3. لون `priceLarge`

قسم الألوان في [`dimensions.md`](../dimensions.md) §10 يجعل السعر بلون `#F27A1A`. `DESIGN.md` يجعل سعر صفحة المنتج بهذا اللون وسعر البطاقة بـ `cardPrice`. الاثنان على الأبيض عند 2.77:1، حتى عند 18sp العريض، تحت عتبة النص الكبير 3:1.

| | |
|---|---|
| الافتراض المعتمد | `price` و`priceCompact` على البطاقة والسطر: `cardPrice`. `priceLarge` في صفحة المنتج وملخص السلة: `primary` |
| السبب | البطاقة نص صغير والقراءة فيها هي المهمة، وصفحة المنتج لحظة سعر كبيرة تطابق اللقطة والوثيقتين |
| البديل | نقل `priceLarge` إلى `cardPrice` ليمرّ AA على الأبيض |
| مكان التبديل | لون دور `priceLarge` في `DooryTypography` |

## 4. لون القيمة الثانوية في الفلاتر

§6 يقيس القيمة تحت عنوان الفلتر بـ `#999999` (`textMuted`). هذا اللون على الأبيض يقارب 2.8:1.

| | |
|---|---|
| الافتراض المعتمد | أي قيمة يقرأها المتسوّق (فلتر، وصف، تاريخ داخل صف) تستخدم `textSecondary` `#666666` |
| `textMuted` | تلميح زخرفي لا تترتب عليه قراءة، أو نص فوق صورة داكنة لاحقاً |
| البديل | الإبقاء على `textMuted` مطابقةً للبكسل |
| مكان التبديل | لون سطر القيمة في `ListRow` |

## 5. شارة عدد السلة

اللقطات تعرض شارّة على أيقونة السلة. لا يوجد نص يحدّد إن كان العدد كمية القطع أم عدد الأسطر.

| | |
|---|---|
| الافتراض المعتمد | مجموع الكميات في السلة، لا عدد المنتجات المختلفة |
| الإخفاء | العدد 0 يخفي الشارة |
| السقف | فوق 99 يُعرض `99+` |
| الرسم | ارتفاع 16 dp، حشو أفقي 4 dp، نصف قطر pill، تعبئة `primary`، نص 10sp / 700 / `textOnStrong`. موضعها أعلى نهاية أيقونة السلة وداخل خلية التبويب |
| القراءة | «السلة، 3 منتجات» عند وجود عدد، و«السلة» عند غيابه |
| البديل | عدد الأسطر فقط، أو إظهار الصفر |
| مكان التبديل | دالة واحدة تحوّل `quantityTotal` إلى نص الشارة |

## 6. طبقة تعتيم الورقة

لقطة `15-sort-sheet` تُظهر الصفحة خلف الورقة باهتة. نسبة التعتيم غير مقاسة.

| | |
|---|---|
| الافتراض المعتمد | `#66000000` (أسود 40٪) |
| البديل | 32٪ أو 54٪ بعد قياس اللقطة الكاملة |
| مكان التبديل | `barrierColor` في `DoorySheet` |

## 7. حجم الشعار في الدخول

كلمة «دوري» في شريط 56 تستخدم 24sp. شعار ترينديول في شاشة الدخول رسم أكبر، ولا يُقاس كسطر نص.

| | |
|---|---|
| الافتراض المعتمد | `wordmarkDisplay` 40sp / 52 / 700 / `primary` في P1 |
| البديل | 32sp أو 48sp بعد اعتماد لقطة الدخول |
| مكان التبديل | خاصية `size` في `DooryWordmark`، والقيمة `display` |

## 8. محاذاة عنوان الشريط العلوي

لقطتا الفلترة والطلبات تضعان العنوان في الوسط بصرياً، مع رجوع على البداية وإجراء على النهاية. بعض العناوين الطويلة ستضيق في الوسط.

| | |
|---|---|
| الافتراض المعتمد | العنوان في وسط `DooryAppBar` بارتفاع 56. الرجوع على البداية. الإجراء النصي على النهاية. عنوان طويل ينتهي بـ `ellipsis` على سطر واحد |
| البديل | العنوان على البداية بعد زر الرجوع، وهو أنسب للعناوين الطويلة |
| مكان التبديل | محاذاة عنوان نسخة `title` |

## 9. قطر شارة عدد الألوان

§6 يذكر «شارة عدد الألوان دائرة 48 dp». على بطاقة عرضها 193.5 dp دائرة 48 تغطي ربع الصورة، بينما اللقطة `13-listing` دائرة صغيرة فيها رقم. رقم الـ dump يطابق منطقة لمس لا الرسم.

| | |
|---|---|
| الافتراض المعتمد | رسم بقطر 28 dp، ورقم `captionStrong`، وخلفية `surface`، وظل `favorite`. منطقة الضغط 44×44. تظهر عندما `colorCount > 1` |
| موضعها | أسفل نهاية الصورة، مع حشو 8 dp |
| البديل | رسم بقطر 48 dp كما في نص القياس |
| مكان التبديل | قطر `ColorCountBadge` |

## 10. لون القلب الممتلئ

اللقطة قلب مفرغ. لون الامتلاء غير مقاس. الكود الحالي يستخدم `danger`.

| | |
|---|---|
| الافتراض المعتمد | القلب الممتلئ `danger` `#BB0000`، والمفرغ `textPrimary` فوق دائرة `surface` |
| البديل | الامتلاء بلون `primary` |
| مكان التبديل | لون أيقونة الحالة `selected` في `FavoriteButton` |

## 11. السعر المشطوب بجانب السعر أو فوقه

اللقطات تعرض السعر الحالي أوضح من المرجعي، والمرجعي مشطوب بجانبه أو قربه.

| | |
|---|---|
| الافتراض المعتمد | صف أفقي: السعر الحالي على البداية، ثم 4 dp، ثم المشطوب. إن ضاق العرض ينزل المشطوب سطراً ثانياً |
| البديل | المشطوب دائماً فوق السعر الحالي |
| مكان التبديل | ترتيب أبناء `PriceBlock` |

## 12. زر «تسجيل الدخول» في رأس الرئيسية

§2 يقيس الزر 104×33 dp بزاوية ≈ 8. سلّم الأزرار المعتمد يبدأ عند 36. الزر نفسه مكوّن P2، ويُذكر هنا حتى لا يُبتكر ارتفاع 33 لاحقاً.

| | |
|---|---|
| الافتراض المعتمد | `DooryButton` بحجم `h36` ونصف قطر `radius8`، والعرض يحتضن النص مع حشو أفقي 12. لون ثابت `primary` بلا تدرّج |
| البديل | ارتفاع 33 dp خارج السلّم لمطابقة البكسل |
| مكان التبديل | حجم الزر عند بناء رأس P2 |
