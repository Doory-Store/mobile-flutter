# مقاسات ترينديول المرجعية (dp)

القياسات مأخوذة من تطبيق Trendyol الرسمي، الإصدار 7.71.1، على المحاكي `emulator-5554` (Pixel 8a، API 35). اللغة العربية والبلد المملكة العربية السعودية.

- الشاشة 1080×2400 px بكثافة 420 dpi، أي **411×914 dp**. التحويل: `dp = px / 2.625`.
- مصدر كل رقم هو حدود العناصر (`bounds`) في ملفات `uiautomator dump`، أو مسح بكسلات الصور بـ Python/PIL. ملفات المصدر في `C:\Users\bahaa\Desktop\Doory\trendyol-ref\screens\` وعلى الـ box في `/workspace/shots/trendyol-app/screens/`.
- الأرقام المقرّبة بنصف dp أو أكثر مكتوب جنبها «≈». أحجام الخطوط مستنتجة من ارتفاع سطر النص، لذلك هي تقديرية (±1sp).
